# Manual de uso — Microscopio
Laboratorio de Rumiología (UTEQ). Guía de ejemplo para FileSearch; reemplazar por el
manual elaborado por los laboratoristas.

## Identificación
Clase YOLO: microscopio.
Función: observación de preparaciones asociadas a prácticas de rumiología y
morfología microscópica.

## Componentes
Oculares, objetivos, platina, macrométrico/micrométrico, fuente de luz.

## Procedimiento de uso
1. Colocar el portaobjetos y comenzar con el objetivo de menor aumento.
2. Enfocar con el macrométrico y afinar con el micrométrico.
3. Subir aumentos de forma progresiva. Usar aceite de inmersión solo si la guía lo pide.
4. Bajar el platina, retirar la preparación y apagar la luz al terminar.

## Seguridad
No tocar lentes con los dedos. Manipular preparaciones con guantes si aplica.
Transportar el microscopio con ambas manos (brazo y base).

## Mantenimiento
Limpiar oculares y objetivos con papel para lentes. Guardar cubierto.
Reportar holgura en la platina o lámpara defectuosa.
