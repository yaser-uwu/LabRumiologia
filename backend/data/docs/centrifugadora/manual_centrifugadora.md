# Manual de uso — Centrifugadora
Laboratorio de Rumiología (UTEQ). Guía de ejemplo para FileSearch; reemplazar por el
manual elaborado por los laboratoristas.

## Identificación
Clase YOLO: centrifugadora.
Función: separar fases de muestras por fuerza centrífuga para análisis posteriores.

## Componentes
Rotor, tubos compatibles, tapa de seguridad, control de tiempo y rpm.

## Procedimiento de uso
1. Balancear tubos de masa equivalente en posiciones opuestas.
2. Cerrar la tapa de seguridad antes de programar rpm y tiempo del protocolo.
3. Iniciar el ciclo y no intentar abrir hasta la detención completa.
4. Recuperar el sobrenadante con pipeta según la práctica.

## Seguridad
Nunca abrir en movimiento. Usar tubos compatibles con el rotor.
Riesgos mecánicos y de aerosoles. Bata y guantes.

## Mantenimiento
Limpiar derrames en el rotor. No usar si la tapa o el interlock fallan.
Reportar vibración excesiva.
